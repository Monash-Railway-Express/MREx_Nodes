# MREx CAN Logger

When the CAN Logger node is on, you can access logs wirelessly. Connect to the wifi network "MREx CAN Logger", password "YesWeCAN".

To download CSV log files, go to http://10.0.0.1 and copy the link to the log file that you want to download.

To view a live feed of CAN messages, go to http://10.0.0.1/feed
